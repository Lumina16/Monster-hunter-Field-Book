# Development history

This is a consolidated feature history, not a reconstructed Git commit timeline.

1. Built the World/Iceborne offline field guide with overview, bestiary, weapons, recipes, maps, field notes and progression.
2. Corrected search/filter graphics, clear controls, alignment and spacing. Added rotating disclosure triangles and coordinated content transitions.
3. Added linked item details, rarity/status weapon-tree symbols, database Info navigation and conditional crafting methods.
4. Replaced progression with story-stage Speedrun checklists and sequential animated unlocks, World completion gating, Iceborne continuation and reset controls.
5. Expanded data coverage to armour, decorations/slots, skills, charms, Kinsects, Palico equipment, specialised tools, canteen, small monsters and endemic life.
6. Added resource-library access, map/base atlases, facility directories, expanded field notes and descriptive expandable credits.
7. Refined compact presentation, icon coverage, themes, gradients, transitions, global effects and smooth search dismissal. Removed weapon-photo overlays and movement-GIF experiments at the user's request.
8. Organised Settings with colour wheels, theme presets, saved looks, typography, effects, transitions, reading/navigation controls, music and reviewed backup/reset operations.
9. Fixed exact Bestiary column selection, including dense manual grids on mobile.
10. Prepared GitHub publication. An interrupted upload lost the temporary source workspace before its final commit. Recovered the complete runtime/data/assets from the saved standalone app and rebuilt it byte-for-byte with a new offline builder. Earlier extraction scripts are not part of this recovered package.
11. Fixed Settings group defaults and the missing gap between Gradients and Saved visual presets. Added and passed a current DOM regression check before publication.

A native Kotlin Android version is planned as a separate assignment. Requirements will be discussed with the user before native implementation begins.
